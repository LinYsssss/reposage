# RepoSage 文档索引

本目录保存面向使用者的项目文档：当前实现全景、架构、数据库、接口、消息队列、RAG/AI 审查设计、部署与配置、本地联调和服务器部署。

## 文档职责与事实来源

- 根目录 [`README.md`](../README.md)：项目入口、当前能力状态、快速开始、常用配置与测试命令。
- [`00_项目详细介绍.md`](00_项目详细介绍.md)：当前实现的端到端全景，重点说明架构、数据流、工程取舍与尚未贯通的边界。
- [`14_当前功能与实现状态说明.md`](14_当前功能与实现状态说明.md)：逐项解释用户功能、审查执行过程、Agent/SCM/沙箱成熟度和推荐演示路径。
- 专题文档：深入说明数据库、接口、MQ、RAG、部署或 SCM/沙箱。
- 如文档之间出现冲突，以当前代码、`backend/src/main/resources/application*.yml`、部署模板和 Flyway 迁移为最终事实来源。
